# Role Statement – UX/UI Designer

**Name:** Phichayathida Laeae  
**Student ID:** 6631503030  
**Role:** UX/UI Designer  

As the UX/UI Designer of Halal Chiang Rai, my main responsibility was to design an intuitive, clear, and accessible interface that helps Muslim students, residents, and visitors explore restaurant information in Chiang Rai. I focused on reducing the effort of searching across scattered sources while clearly separating verified facts from information that still needs confirmation.

I designed the overall visual theme using a modern pink-and-white color palette and structured the user flow across core screens, including the Home page with the AI Restaurant Assistant, zone-based exploration, Search and Result cards, the Favorites collection, and the Sign-In modal. I also ensured bilingual support (Thai and English) so both local users and international visitors can navigate easily. Throughout development, I collaborated closely with the team to refine the UI from early wireframes into the final responsive interface and presented the live UI/UX walkthrough.

## Reflection

### 1. Lessons Learned

Working on this project taught me that building a software application requires much more than just creating attractive screens or writing code. Every step—from gathering user requirements and designing user flows to coding, testing, and ensuring security—must connect smoothly. Using AI significantly improved our development and ideation speed. One thing that got better in our project was rapid prototyping and problem-solving; we could quickly test layout concepts, refine bilingual interface text, and fix technical bottlenecks faster than working manually. 

However, one thing that got worse was the risk of relying too heavily on AI-generated outputs without fully verifying them. At times, AI suggested UI structures or code snippets that looked complete at first glance but did not match our actual user flow or data structure, requiring careful review and manual adjustments. I learned that AI is a powerful assistant, but strong team communication, user testing, and human judgment are essential to maintain real quality.

### 2. Where I Stand in the Software Industry Today

I see myself as an emerging junior designer and developer who is building a strong foundation in the software industry. In today’s AI era, basic design and coding tasks are much faster, which means simply knowing how to use tools is no longer enough. I believe my value lies in understanding real user pain points, designing logical user experiences, and knowing how to guide and evaluate AI outputs critically rather than accepting them blindly.

### 3. My Plan

Next year, I plan to strengthen my UX/UI design portfolio, practice user research and usability testing more deeply, and improve my frontend development skills so I can turn my own designs into working code more independently. I also aim to gain real-world experience through an internship.

In five years, I hope to work as a well-rounded Product Designer or UX/UI Specialist who bridges user-centered design and AI-driven technology to build meaningful, accessible digital products.
