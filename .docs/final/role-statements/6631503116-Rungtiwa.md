# Role Statement – Product Owner

As the Product Owner of Halal Chiang Rai, my role was to help plan the project and decide what features the application should have. I focused on the needs of users, especially Muslim students, residents, and tourists who want to find halal restaurants in Chiang Rai.

I helped discuss ideas with the team, define requirements, organize features, and decide which parts were important for the application. Some of the main features we planned included searching for restaurants, viewing restaurant details, checking halal status, and finding places on the map. I also helped communicate ideas and project requirements with other team members.

## Reflection

### 1. Lessons Learned

Working on this project with AI taught me that developing an application takes more than just writing code. We needed to understand the requirements, plan the features, design the application, and test whether everything worked correctly. AI helped us work faster, especially when coming up with ideas and writing code. One thing that got better was the development speed because we could try different ideas and solve some problems more quickly.

However, one thing that got worse was that sometimes we depended too much on AI. There were times when we got code that looked correct but did not fully understand how it worked. We still had to check, test, and fix things ourselves. I also learned that we should not ignore quality and security just because AI helps us develop faster. Teamwork and communication were also important because everyone needed to understand the project and their responsibilities.

### 2. Where I Stand in the Software Industry Today

I think I am still a beginner in the software industry. I have learned some things from this project, but I still need to improve my programming and problem-solving skills. AI makes development easier in some ways, but I don't think we can depend on it for everything. We still need to understand the code and know how to fix problems ourselves.

### 3. My Plan

Next year, I want to improve my programming skills, especially Python, JavaScript, and databases. I also want to build more projects, improve my portfolio, and gain experience from an internship. I want to become more confident in coding without depending too much on AI.

In five years, I hope to have a job in the software industry and have enough experience to work on real projects. I also want to keep learning new technologies and use AI to help with my work while still understanding what I am doing.
