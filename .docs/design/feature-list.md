# Feature List — Halal Chiang Rai

## Implemented

- **Home discovery:** Local recommendation prompt form, area shortcut cards, and
  featured restaurant list.
- **Search:** query field for restaurants, menu items, areas, cuisine, and
  related halal text.
- **Recommendations:** Home prompt understands area, cuisine, and budget
  preferences.
- **Result ranking:** matching query/area/cuisine results are scored, with
  verified records receiving a ranking boost.
- **Restaurant cards:** cuisine, area, price level, opening hours, verified
  badge, and favorite toggle.
- **Restaurant detail sheet:** description, location, opening hours, menu,
  prices, save action, and Google Maps directions.
- **Favorites:** local account gate and per-account saved restaurant list.
- **Account:** local sign-up/sign-in, language selection, saved count, and
  sign-out.
- **Localization:** Thai and English translations for the implemented UI.
- **Responsive UI:** mobile-first 320px minimum target and 480px app shell.
