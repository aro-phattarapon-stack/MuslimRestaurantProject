# Session Logs & Privacy Controls

## 1. Consent & Privacy Controls

* **Informed Consent Status:** All 12 participants (`100%`) explicitly consented to data collection (`ยินยอม`) and media recording (`อนุญาต`) for educational evaluation purposes via the post-test form (`Halal Nue Sud  (1).xlsx`).
* **De-identification Policy:** To protect participant privacy in a public GitHub repository, all personally identifiable information (including Student IDs collected from 9/12 respondents) is omitted from repository documentation. Participants are referenced strictly by anonymized codes (`U01`–`U02` for moderated task-timing logs; `R01`–`R12` for post-test SUS responses).
* **Access Control:** Raw form exports containing Student IDs and any session photos/screen recordings are stored in a restricted-access team folder (accessible only to project team members and course instructors).
