# User Guide

## Browse and Search

1. Open Home and choose an area, or open Search.
2. Enter a restaurant, menu item, or area in the search field.
3. Select a restaurant card to view its available details.
4. Confirm halal status with the restaurant before visiting.

## Favorites and Account

The prototype requires a local browser account to save favorites. Account and
favorite data are stored in that browser; this is not a production account
service.

## Directions and Language

Use the restaurant detail's directions action to open Google Maps. Switch
between Thai and English using the language control.
